## 1. 问题

传统方案需要**额外修建独立鱼道**（如七级结构），存在三个缺陷：

| 缺陷 | 具体后果 |
|---|---|
| **占额外空间** | 平面与剖面都要为通道让位，挤占泊位与作业面 |
| **易受风浪破坏** | 鱼道是独立结构，与主体不同寿命；破坏后需单独抢修 |
| **需额外模具** | 独立构件 = 独立制造链，增加制造成本与维护复杂度 |

在抗台风场景下，「鱼道先坏、主体尚好」是一种**独立失效模式** ——
即抗台风的受力结构还在，生态连通已经断了。

## 2. 提议的升级

把独立鱼道**升级为集成式多级活水生态通道**：

>传统独立鱼道（如七级结构）占用额外空间且易受风浪破坏；
> 本方案将其**升级**为融入承重结构的 **10 柱 5 墙** 与 **6 柱 3 墙** 阵列。
> **墙体既承担抗台风受力，其预留孔洞又构成多级活水生态通道**，
> 实现**结构承重与生态连通的拓扑级融合**。

| 模块 | 阵列 |
|---|---|
| MOD-STD（27×27×8 m） | **10 柱 5 墙** |
| MOD-DM（27×27×6 m） | **6 柱 3 墙** |

**一套模具，同时解决三大痛点**：

|痛点 | 外挂鱼道方案 | 本方案 |
|---|---|---|
| 抗台风 | 鱼道单独承受，易损 | 墙体本身受力，通道寄生其中 |
| 模块组装 | 需额外接口与模具 | **榫卯柱阵列即接口** |
| 生态通水 | 独立构件，单独维护 | **同套模具同时解决** |

## 3. 实测数据（几何实算）

模块 27×27×8 m，口径来自编码规范 V6.4 §4.1.1 / §4.3 / §4.6.3：

| 通水路径 | 规格 | 贯通面积 |
|---|---|---|
| 承重预留孔洞 | 12 直通榫卯柱 φ300 mm | 0.8482 m² |
| 压载舱体三管束 | φ2000 mm × 3（V6.0） | 9.4248 m² |
| **合计** | — | **10.2730 m²** |

| 指标 | 值 |
|---|---|
| 被移除外挂鱼道（φ2000 单管） | 3.1416 m² |
| **面积倍数** | **3.27 倍** |
| **透水率**（迎水面投影 729 m²） | **1.4092%** |

> **口径声明**：1.4092% 为**几何实算**，
> **非 CFD 实测的流量交换率**。两者物理量不同，不混充。

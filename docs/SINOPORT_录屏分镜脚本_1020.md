### ★★ Ctrl+C 截断指令（务必记住）

**看到这一行就立刻按 `Ctrl+C`：**

```
building foam ...
```

**为什么**（今天实测数据）：

| 时刻 | 状态 |
|---|---|
| 启动后 **3.9 s** | 打印 FreeCAD 版本横幅 |
| 启动后 **43.9 s** | 打印 `building foam ...`，**此时 15 条 PASS 已全部打完** |
| 之后 **9 分 41 秒** | foam 布尔 + 61 管腔 + STEP 导出，**无任何新信息** |
| 最终 | `STATS: {'pass': 18, 'fail': 1}`，唯一 FAIL 是 foam 体积判据（**已知待标定项**） |

> **44 秒拿 15 条 PASS；多跑 9 分 41 秒只多换 3 条次要 PASS + 1 条 FAIL。**
> **性价比极差，必须截断。**

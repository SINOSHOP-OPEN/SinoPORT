# SINOSHOP 海洋家园 · AIGC 提示词库

> **用途**：直接用于 Midjourney / Stable Diffusion / Flux / Sora / 可灵 / 即梦 / 海螺 等主流生成模型。
> **许可**：本提示词库属 **T1 大众层**，可自由用于非商业创作；商业使用需授权。
> **重要**：本库中的所有描述词**只描述形态与氛围，不含任何工程尺寸、材料配方或技术机理**。
> 这既是保密要求，也确实更适合生成模型——描述尺度会让画面失真，描述氛围才出好图。

## 〇、通用风格前缀（建议统一使用）

```
cinematic ocean engineering concept art, volumetric god rays through deep teal water,
architectural scale, ultra detailed, matte PBR materials, subtle atmospheric haze,
8k, filmic color grading, teal and amber complementary palette
```

**负向词（Negative Prompt）**：
```
lowres, blurry, distorted geometry, text, watermark, logo, cartoon, oversaturated,
cluttered, floating debris, unrealistic proportions, fisheye, jpeg artifacts
```

## 四、负面场景词库（避免生成物违反工程常识）

```
floating without support in mid-air, exposed cables, scaffolding, construction cranes,
dry land, beach, palm trees growing on steel, tanks or barrels on deck,
corrugated shipping containers, military aesthetics, submarine hulls, ship wrecks,
fantasy floating islands, magic runes, steampunk gears, anime style
```

> 说明：这些负向词既保画面质量，也避免把"海洋家园"生成成与实际形态无关的意象。

## 五、参赛建议（对接 AIGC 视觉共创挑战赛）

1. **用官方白模垫图**（L2 归一化白模，可在开发者沙盒包获取）→ 保证结构还原度。
2. **主题对齐四乐章**：每个主题至少投 1 稿，便于评审核对。
3. **提交三件套**：成图 + 使用的提示词全文 + 使用的垫图编号。
4. **署名规范**：作品页标注 `@作者名`，被收编进官方 MV 的作品**永久署名**。

## 六、迭代建议（提高出图质量）

| 症状 | 调整 |
|---|---|
| 画面太"科幻" | 删 `sci-fi, futuristic, glowing neon`，加 `documentary, real engineering` |
| 结构散乱 | 加 `single unified structure, coherent assembly, engineering plausibility` |
| 尺度感缺失 | 加 `tiny human silhouettes for scale, colossal monument` |
| 颜色过艳 | 加 `muted palette, natural light, restrained saturation` |
| 太空旷 | 加 `cluttered with functional detail, walkable surfaces, handrails, signage` |

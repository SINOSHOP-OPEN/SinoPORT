# 创作者招募令

> **SINOSHOP 海洋家园 · 全球视觉共创计划**
> 一份写给画师、视频创作者、三维艺术家、算法工程师的公开邀约

---

## 引子：一段关于"造物"的话

人类的下一个栖居地不在陆地上，在海上。

我们把一条扁平的椭圆通道安放进深海，让它定深悬浮、稳稳地横跨在洋流之上；
我们在通道里种下红树林，把轨道、公路、生活平台叠进同一套模数；
当台风从外海扑来时，有一排单元会迎上去，把惊涛一寸一寸揉碎。

这件事我们已经做了很久。**现在我们要把手松开一部分。**

不是全部——工程的核心仍有我们的底线。但**形态、氛围、音乐、影像、算法，
这些东西一旦被更多人的想象力接管，就会长成我们一个人想象不出的样子。**

所以我们把白模、提示词、渲染切片、场景规格、音频分轨都摆到桌上。
你来，我们一起以善驭澜。

## 我们提供什么

### 给视觉创作者（无需申请，即刻下载）

- **概念图集**：悬浮隧道全景、管段内部、红树林家园、星空海面
- **AIGC 提示词库**：中英双语结构化提示词 + 负向词 + 迭代建议
  （四大主题 × 形态母题 × 光照氛围 × 镜头语言）
- **工程渲染切片**：108 秒工程展示的纯动态片段，可直接作 AI 视频垫图

> 用 Midjourney / SD / Flux / Sora / 可灵 / 即梦，垫着我们的图，
> 生成你自己的海洋家园。

### 给三维与游戏开发者（实名申请，对等获取）

- **19 个归一化白模**（GLB + OBJ + MTL）：管段、桁架、外壳、管束、组合总成、
  壁面板、走廊段、三族功能舱、连接件（开/闭两态）、调载舱（剖/闭两态）、
  引桥轨道段、消浪单元（分解）、引桥水域场景、系泊场景
- **场景规格与装配规则**：比例表、拼装建议、中性材质配色表
- **场景墙 A–G**：七个可接入的技术命题，各含「可开放贡献」与「内部边界」
- **《善乐生》分轨音频**：笛、二胡、古琴、古筝、编钟、自然声场、唱腔、群唱

> 高校团队、独立开发者、游戏工作室——**拿到的是同一份包、同一份规范、同样的权限。**
> 唯一的差别是：你愿意贡献多深，我们就回得多深。

### 给所有人（都可以做）

- **参与共创挑战赛**，作品收编进官方 MV，**永久署名**
- **提 Pull Request**，把你的原型、勘误、踩坑经验留在仓库里

## 你能得到什么

**最高荣誉不是奖金，是收编。**
你的作品被正式纳入《善乐生》官方 MV，成为官方视觉的一部分——
每一个看 MV 的人都会看到它，而署名栏永远有你的名字。

**实物**：定制版「一钟一诺」编钟模型 / 悬浮港微缩摆件。

**技术合伙人**：表现优异者获 SINOSHOP 联合实验室「技术合伙人」证书，
并获得进入更高层级定向合作的机会。

**真实落地**：被采纳的算法与模型，会进入真实的工程验证流程，
贡献者以哈希存证方式被永久记录在案。

## 三道赛题

### 赛题一 · AIGC 视觉共创
围绕四个乐章主题——**悬浮隧道 / 善乐栖居 / 惊涛平复 / 星垂海隅**——
用 L1 素材垫图，创作 AI 图像或 AI 视频。
**提交**：成图 + 提示词全文 + 所用垫图编号。

### 赛题二 · 数字孪生极客马拉松
用 L2 白模做出可运行的技术原型：
- **音乐向**：用 TouchDesigner 做「海浪音频实时驱动的悬浮港灯光秀」
- **工程向**：用 Unity / UE5 做「参数可调、浮体响应实时可见」的交互演示
- **算法向**：为一个场景墙命题（A–G 任选）给出可运行的解法或公式

### 赛题三 · 永不沉没的开源库
给仓库提 PR：修正规格、补充引擎适配经验、提交你的原型。
我们审的不是代码量，是**有没有把别人往前推了一步**。

## 关于保密，说明白

我们开源，但**有三条线不碰**：

1. **动态载荷抵消系统的机理与算法**
2. **浮体高度恒定潮汐发电的技术细节**
3. **悬浮防波堤消浪发电的技术细节**

这三块是工程的骨血，**永远不进入任何公开物料**——
包括不以"暗示"的方式出现。公开层给你的每一个模型都已做**尺度归一化**
（最长边归一为 1.0、材质中性化、元数据清除），
**你拿到的模型里没有任何真实尺度、材料配方或控制参数**。

这不是不信任你，是保护这个项目活到建成的那一天。
**能公开的，我们已经全部给你了。**

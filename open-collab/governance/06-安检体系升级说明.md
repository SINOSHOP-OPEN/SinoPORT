## 三、闸门 ③ 详解：视频帧安检

### 为什么必须单独做

工程展示视频的字幕与标题卡是用绘图库**烧进位图**的。
文本扫描器看不到它们——这正是「总宽尺寸真值」能一路走到公网的原因。

### 判定口径

在原有禁项表之外，补三类正则：

| 规则 | 样例 | 理由 |
|---|---|---|
| 裸米制 | 阿拉伯数字 + 米制单位 | 原有 |
| 中文米制量词 | 中文数字 + 量词 + 米 | **原扫描器盲区** |
| 裸四位以上数值 | 无单位裸数字（如工程编号型） | 极可能是工程尺寸真值 |

### 运行

```bash
python scan_video_overlay.py <video.mp4> [抽帧间隔秒]
```

退出码：`0` = PASS，`1` = FAIL，`2` = 需人工核验（OCR 不可用时）。

## 四、闸门 ④ 详解：3D 资产几何安检

### 为什么必须单独做

GLB 的顶点坐标**就是尺寸真值**；JSON chunk 里还明文写着包围盒 min/max。
改文件名（`某内部型号代号_shell.glb` → `floating_tunnel.glb`）是自欺欺人——
**几何本身就是答案**，用任何 3D 软件量一下就知道。

### 归一化口径（公开层强制）

1. 每个模型**独立**归一：包围盒最长边 = 1.0
   （不用全局统一比例——那仍让人能拿已知参照物反推绝对尺度）
2. 包围盒中心平移到原点（消除安装偏移量这一侧信道）
3. 材质名中性化（去牌号、去介质类别）
4. 元数据清除（生成器注释、模型代号、单位声明）
5. 文件名去内部代号

### 校验项

| # | 校验 | 判据 |
|---|---|---|
| 1 | 归一化有效 | 最长边 == 1.0（误差 < 1e-4） |
| 2 | 中心在原点 | 三轴中心偏移 < 1e-4 |
| 3 | 无绝对尺度残留 | 包围盒元数据所有分量 \|v\| ≤ 1.0001 |
| 4 | 无内部代号残留 | 全文检索代号黑名单 |
| 5 | 材质名中性 | 全部以 `mat_` 开头 |
| 6 | 几何完整 | 顶点数/三角面数与源模型一致 |

## 三、开发者问卷

请说明以下四项（简短即可）：

1. **你的方向**：三维美术 / 游戏开发 / 交互工程 / 算法研究 / AIGC 创作 / 其他
2. **你打算做什么**：打算用白模做漫游场景？做引擎适配？做一个 AIGC 短片？
3. **是否会提交 PR**：是 / 否（不影响获取权限，只影响后续邀约优先级）
4. **你的署名偏好**：希望显示的署名（可匿名）

> 问卷只用于了解用途与建立联系，**不收集机构敏感信息**。
> 我们不承诺按身份分级——**拿到的是同一份包、同一份规范、同样的权限**。

**提交渠道**：仓库 Issues / Discussions，或 `docs/获取方式.md` 里的联系方式。

## 四、分轨音频清单

| 公开名 | 乐器 | 用途建议 |
|---|---|---|
| `flute` | 笛子 | 主旋律驱动、节奏基准 |
| `erhu` | 二胡 | 人声化情绪线、慢速转场 |
| `guqin` | 古琴 | 点状装饰、留白段落 |
| `guzheng` | 古筝 | 高速纹理、粒子效果 |
| `bell` | 编钟 | 时间点标记、转场重音 |
| `nature_field` | 自然声场 | 环境底噪、海浪循环 |
| `vocal` | 唱腔 | 叙事主轴、字幕对位基准 |
| `chorus` | 群唱 | 和声铺底、空间感 |

> **小贴士**：`bell` 轨只有 5 个击点，是全曲的**天然节拍标记**——
> 做灯光秀或粒子动画时，用它对拍最准。
> `vocal` 轨含完整唱词，可直接做字幕对位或音频驱动唇形。

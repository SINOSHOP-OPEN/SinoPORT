## 〇、共同条款

### 赛程

| 阶段 | 时段 | 内容 |
|---|---|---|
| 报名 | 第 1–2 周 | 提交报名表 + 领取素材包 |
| 创作 | 第 3–6 周 | 自由创作，可中途发进度帖 |
| 截稿 | 第 7 周 | 提交作品与说明 |
| 初评 | 第 8 周 | 评审团初评 + 社区票选 |
| 终评 | 第 9 周 | 专家终评 + 公示 |
| 收编 | 第 10 周 | 获奖作品集成进官方 MV 与物料 |

### 参赛资格

- 年满 18 周岁的个人或团队
- **不要求**高校/企业身份——**独立开发者与学生与专业团队同池竞技**
- 需遵守《二创授权协议》与仓库红线

### 提交物规范（三赛通用）

| 项 | 要求 |
|---|---|
| 作品文件 | 原始工程文件 + 导出成品（图像 PNG/JPG；视频 MP4；代码仓库链接） |
| 创作说明 | 使用的素材编号、提示词全文、关键技术选择（300 字以内） |
| 可复现 | 评审应能按你的说明复现你的过程 |
| 授权确认 | 确认作品为原创、接受官方按协议第四条使用 |

### 评审维度（共 100 分）

| 维度 | 权重 | 说明 |
|---|---|---|
| 主题契合 | 25 | 是否切中「悬浮隧道 / 善乐栖居 / 惊涛平复 / 星垂海隅」 |
| 工程可信 | 25 | 是否符合海洋工程常识与结构逻辑（不悬浮无支撑、不违背受力） |
| 艺术完成度 | 20 | 构图、光影、色彩、叙事 |
| 创新性 | 15 | 是否提供了别人想不到的视角 |
| 可复现性 | 15 | 说明是否清晰、素材是否正确使用 |

> **特别说明**：使用官方白模垫图**不加分**——因为那是给所有人准备的。
> 加分的是**你怎么用它**。评审不鼓励"照着模型渲染"。

## 一、赛题一 · AIGC 视觉共创

### 赛题
围绕四个乐章主题创作 AI 图像或 AI 视频：
**悬浮隧道 / 善乐栖居 / 惊涛平复 / 星垂海隅**

### 分组
- **A 组｜图像**：单张或系列（3–6 张成组）
- **B 组｜视频**：15–60 秒（可用官方渲染切片作垫图）

### 素材
- L1 大众层：概念图、提示词库、渲染切片（**无需申请**）
- L2 开发者层：19 个归一化白模（**实名申请**）

### 评审特别项
- **叙事连贯**：系列作品之间是否有统一的视觉语言
- **生成可控性**：你的提示词是否体现"控制意识"（而非纯抽卡）
- **反套路**：避免"赛博朋克霓虹"这一过度使用的默认解

| 名次 | 奖励 |
|---|---|
| 一等奖 ×1 | 收编进官方 MV + 永久署名 + 定制「一钟一诺」编钟模型 + 技术合伙人证书 |
| 二等奖 ×3 | 收编进官方物料 + 署名 + 悬浮港微缩摆件 |
| 三等奖 ×8 | 收编进官方社媒矩阵 + 署名 |

## 二、赛题二 · 数字孪生极客马拉松

### 赛题
用 L2 素材，做出一个**可运行**的技术原型。三个方向任选：

| 方向 | 命题 | 技术栈建议 |
|---|---|---|
| **音乐向** | 海浪音频实时驱动的悬浮港灯光秀 | TouchDesigner / Three.js / Web Audio |
| **工程向** | 参数可调、浮体响应实时可见的交互演示 | Unity / UE5 / React Three Fiber |
| **算法向** | 场景墙 A–G 任一命题的可运行解法 | Python / MATLAB / Julia |

### 素材
- L2：归一化白模 + 场景规格 + 《善乐生》分轨音频
- T2+ 定向层（邀约制）：技术原型接口脚手架

### 评审特别项
- **能跑**：评审会实际运行你的原型
- **工程诚实**：不得伪装效果（用假数据冒充实时计算会被取消资格）
- **边界自觉**：如果你的方案触及了不该公开的领域，**主动说明你避开了什么**——这本身是加分项

### 奖励
| 名次 | 奖励 |
|---|---|
| 一等奖 ×1 | 现金奖金（见下方经费说明）+ 技术合伙人证书 + 定向层邀请 + 推荐信 |
| 二等奖 ×2 | 现金奖金 + 技术合伙人证书 + 定向层邀请 |
| 三等奖 ×5 | 现金奖金 + 定向层邀请 |
| 入选 ×20 | 官方技术博客署名发布 + 定向层邀请 |

> **关于奖金规模**：本赛事的现金奖金池由官方按报名规模分级设立，
> 具体金额在报名页公示。**我们不承诺一个先写死的数字**——
> 宁可让奖金跟着真实报名规模走，也不开空头支票。
> 非现金奖励（收编、署名、合伙人身份、定向层邀请）**无条件兑现**。

## 三、赛题三 · 开源库贡献赛

### 赛题
给仓库提有价值的 PR。计分方式：
- 采纳的**勘误型** PR：每条 +2 分（不设上限，鼓励细碎但真实的修正）
- 采纳的**适配型** PR（引擎适配/踩坑记录）：每条 +10 分
- 采纳的**原型型** PR（可运行原型入库）：每条 +25 分
- **评审认可但未采纳**的建议：+1 分（避免"提了就没下文"）

### 特别机制
> **不设上限的贡献积分制**——这是对"细碎但真实"修正的刻意倾斜。
> 一次提交 20 条勘误，价值可能高于一次大重构。

### 奖励
- 积分前 20 名获**技术合伙人证书** + 定向层邀请
- 累计积分最高者获**联合实验室顾问席位**
- 所有采纳 PR **永久署名**于提交历史

## 四、知识产权与收编

1. 作品著作权归创作者所有。
2. 参赛即授权官方按《二创授权协议》第四条使用该作品。
3. **官方不主张排他性独家许可**。
4. 收编作品创作者获得**永久署名权**。
5. 参赛作品**不得**包含第三方受限制素材（如某些商业模型的付费输出），
   违者取消资格并承担责任。

## 五、评审团

- **艺术组**：视觉设计 / 影视 / AIGC 实践者
- **工程组**：海洋工程 / 结构 / 水动力 / 控制
- **社区组**：开源社区活跃贡献者
- **技术组**：官方技术团队（负责红线与工程诚实性审查）

> 评审团名单与回避规则在报名页公示。

## 六、取消资格情形

- 作品含红线内容（三大核心技术信息、真实尺度、材料配方）
- 抄袭或洗稿（AI 生成亦须符合创作规范）
- 违反工程诚实性（伪造数据、伪装效果）
- 使用第三方受限素材未声明
